# Release v2.2.0 - Multi-Platform Chat-to-Speech 🚀

โปรแกรมแปลงแชทเป็นเสียงพูด รองรับ YouTube, Twitch, และ TikTok Live พร้อมระบบแปลภาษาและเสียงสำรอง

### ✨ ฟีเจอร์หลัก (Key Features)
*   **Multi-Platform Support:** เชื่อมต่อ YouTube Live, Twitch และ TikTok Live ได้พร้อมกัน
*   **Auto-Translate:** แปลคอมเมนต์ภาษาต่างประเทศเป็นภาษาไทยอัตโนมัติ (Google Translate)
*   **Dual Engine:** ใช้ Edge TTS เป็นหลัก และสลับไปใช้ gTTS (Google) ทันทีหากมีปัญหา
*   **Smart Queue:** จัดลำดับการอ่านออกเสียง ป้องกันเสียงซ้อน และคำนวณดีเลย์ตามความยาวข้อความ
*   **GUI & CLI:** ใช้งานง่ายผ่านหน้าจอ Graphic หรือใช้คำสั่งผ่าน Command Line

### 🛠️ สิ่งที่ปรับปรุงในเวอร์ชันนี้
1.  ปรับปรุงเสถียรภาพการเชื่อมต่อ (Auto-Reconnect)
2.  เพิ่มระบบกรองคำหยาบ (Profanity Filter) ที่ตั้งค่าเองได้
3.  ปรับแต่งดีเลย์ต่อตัวอักษรได้แบบ Real-time ผ่าน GUI
4.  รองรับการเปิด Console ควบคู่ไปกับ GUI เพื่อดู Log การทำงานอย่างละเอียด

### 📦 วิธีใช้งานแบบ EXE
1.  ดาวน์โหลดไฟล์ `ChatTTS-v2.2.0-Windows.zip`
2.  แตกไฟล์ ZIP ลงในโฟลเดอร์ที่ต้องการ
3.  รัน `ChatTTS.exe` เพื่อเริ่มใช้งาน
