# Release v2.2.1 - Config Refresh Fix & Installer Update 🛠️

เวอร์ชันนี้เน้นการแก้ไขปัญหาทางเทคนิคเพื่อให้การตั้งค่าใช้งานได้ทันทีโดยไม่ต้องรีสตาร์ทโปรแกรม และเพิ่มความสะดวกในการติดตั้งผ่านตัวติดตั้ง (Installer)

### 🛠️ สิ่งที่ปรับปรุงและแก้ไข (Improvements & Fixes)
*   **Config Refresh Fix:** แก้ไขปัญหาการเปลี่ยนค่าคอนฟิก (เช่น เสียง, ดีเลย์) แล้วโปรแกรมยังใช้ค่าเก่าอยู่ โดยการใช้ระบบ **Session-based Thread Control** เพื่อให้แน่ใจว่าค่าใหม่จะถูกนำมาใช้ทันทีที่กด "START SYSTEM"
*   **Auto Queue Clearing:** เพิ่มระบบล้างคิวข้อความและไฟล์เสียงอัตโนมัติเมื่อเริ่มระบบใหม่ เพื่อป้องกันไม่ให้มีข้อความจากรอบเก่าค้างมาอ่านในรอบใหม่
*   **GUI Cleanup:** หน้าจอ Log จะถูกล้างข้อมูลโดยอัตโนมัติเมื่อกดเริ่มระบบใหม่ เพื่อให้เห็นสถานะการทำงานล่าสุดที่ชัดเจน
*   **Inno Setup Integration:** เพิ่มไฟล์สคริปต์ `.iss` สำหรับสร้างตัวติดตั้ง (Setup.exe) ทำให้ผู้ใช้สามารถติดตั้งโปรแกรมลงในเครื่องได้สะดวกเหมือนโปรแกรมทั่วไป
*   **CLI Improvement:** ปรับปรุงความเสถียรในการทำงานร่วมกับ Engine ตัวใหม่

### 📦 ไฟล์ที่เกี่ยวข้อง
1.  **ChatTTS-v2.2.1-Setup.exe:** ตัวติดตั้งโปรแกรมสำหรับ Windows (แนะนำ)
2.  **ChatTTS-v2.2.1-Windows.zip:** โปรแกรมแบบ Portable (ไม่ต้องติดตั้ง)
3.  **setup.iss:** สคริปต์สำหรับ Inno Setup สำหรับนักพัฒนา
